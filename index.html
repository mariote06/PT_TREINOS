Cópia de segurança

Os dados ficam guardados só neste browser. Guarda uma cópia para não os perderes.
Sincronizar entre dispositivos (PC e telemóvel)
Guarda os teus dados num repositório privado do GitHub e mantém o computador e o telemóvel iguais. Repete os mesmos passos em cada aparelho.
Como preparar (só uma vez)
  1. No GitHub, cria um repositório privado chamado ciclo-dados (marca «Add a README file»).
  2. Em github.com/settings/personal-access-tokens/new cria um token: «Repository access» → Only select repositories → ciclo-dados; «Permissions» → Repository permissions → Contents: Read and write. Copia o token (começa por github_pat_).
  3. Cola aqui o repositório e o token, e carrega em «Ligar e sincronizar». Faz o mesmo no outro aparelho.

Ajustar plano

Equipamento disponível em casa:
+ Introduzir nova patologia
Os treinos de cada semana mantêm a ordem e passam para os dias escolhidos (o último fica no último dia). As aulas de grupo não mudam. Se escolheres menos dias do que treinos, os treinos do meio ficam de fora.

Ciclo de protocolo

A app ajusta cada fase a este número e distribui os dias. Mantém sempre o treino mais longo (ex.: corrida longa) no último dia.
Equipamento disponível em casa:
Intermédio = protocolo como está. Iniciante reduz cerca de 25% o volume das corridas e uma série nos exercícios de força. Avançado aumenta cerca de 10%. Com dois clientes, vale o nível mais baixo.
A semana de descarga reduz cerca de 30% do volume e mantém a técnica. Só se aplica a protocolos de treino e não às afinações de prova, à reabilitação nem à prevenção.
